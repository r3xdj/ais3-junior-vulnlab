AIS3 計畫簡介

為提昇學生的資訊安全實務能力，培養具攻防實務力之進階人才，AIS3 於每年暑假七月底舉辦為期 7 天的密集課程。 訓練邀請國際講師、國內專家學者辦理以產業專題導向之資安暑期課程，內容強調與產業連結，以產業資安需求為導向，引導學生小組製作與展示專題成果並搭配近期資安趨勢議題設計課程內容。

學員事先進行篩選：透過繳交推薦甄選資料或需通過 Jeopardy CTF 類型 pre-exam 後才能參與，並依學員興趣主題組成跨校跨級專案小組，最後兩日以分組專題競賽形式進行，發表專題報告。

AIS3 榮譽考試機制

「AIS3 榮譽考試」是專為評測實戰能力所設計的線上檢定，開放給所有對資安攻防有興趣的在籍學生報名。試題涵蓋 Web 滲透測試、微服務與 API 安全、以及系統權限提升等核心技術。

  • 免除初審： 通過檢定即可直升 7 天資安暑期營隊。
  • 自動證書頒發： 通過者由背景系統自動產出附雷達圖之榮譽證書。
  • 優先組隊： 享有專題競賽優先選組與導師媒合權利。
