常見資安領域與攻防類型

掌握 CTF 競賽與資安實踐中的六大核心技術範疇

Web 安全 (Web Security)

針對網站應用程式與 API 介面進行漏洞挖掘與利用。

  • SQL / NoSQL 注入攻擊
  • 跨站腳本漏洞 (XSS)
  • 伺服器端請求偽造 (SSRF)
  • 身分驗證與 Session 繞過
Web Attack API Vulnerability

逆向工程 (Reverse Engineering)

分析已編譯的執行檔，逆向推導程式運作邏輯與演算法。

  • 組合語言與 CPU 暫存器分析
  • 反組譯工具（IDA Pro, Ghidra）
  • 反動態除錯與程式碼加殼解密
  • 保護機制與演算法逆向
Assembly Decompile

二進位漏洞利用 (Pwn)

尋找作業系統或軟體底層記憶體漏洞以控制程式執行流程。

  • 緩衝區溢位 (Buffer Overflow)
  • ROP (Return-Oriented Programming)
  • 堆疊與堆積漏洞利用 (Heap Exploitation)
  • 繞過記憶體保護機制 (DEP / ASLR)
Memory Exploit Shellcode

密碼學 (Cryptography)

研究古典與現代加密演算法缺陷，進行金鑰破解與密文還原。

  • 古典密碼學與替換密碼
  • 對稱加密攻擊 (AES, DES, CBC Mode)
  • 非對稱加密破解 (RSA, ECC)
  • 雜湊碰撞與偽造攻擊 (Hash Collision)
Encryption RSA / AES

數位鑑識 (Digital Forensics)

分析網路封包、記憶體鏡像與硬碟映像，還原事件經過與證據。

  • 網路封包分析 (Wireshark / PCAP)
  • 記憶體鑑識與分析 (Volatility)
  • 檔案系統分析與隱寫術 (Steganography)
  • 日誌檔分析與入侵追蹤
PCAP Analysis Forensics

雜項 (Miscellaneous / Misc)

包含程式自動化、公開來源情報 (OSINT) 與跨領域綜合應用。

  • 公開來源情報偵查 (OSINT)
  • 自動化腳本寫作 (Python Scripting)
  • 特殊編碼與資料格式解碼
  • 硬體資安與無線電通訊攻擊
OSINT Automation
